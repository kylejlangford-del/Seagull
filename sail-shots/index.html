Preview matches

Check the matches before publishing. An amber badge means the closest boat-data row was more than 30 minutes away — check the boat log and camera clocks agree. A red badge means no capture time or no match could be found at all.

4

Publish

This page has no upload backend of its own, so publishing a new batch is two separate drops: 1) drag the photo files themselves straight into the seagull-sail-shots bucket on the Cloudflare R2 dashboard — keep their filenames exactly as they are, that's how the site finds them. 2) Download the manifest below and upload just that one file using GitHub's Add file → Upload files page inside the sail-shots/ folder (replacing manifest.json) — it's small, so this step stays on GitHub. Or send the manifest and photo files to Claude in chat and ask for them to be published.
