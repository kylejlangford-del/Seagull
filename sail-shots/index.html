Boat data file

Upload the CSV exported from the boat — a header row plus one row per timestamp. (Not a CSV yet? Send the raw file to Claude in chat first and ask for a CSV conversion, then come back here.)

Optional — pick heading and true-wind-angle columns and each photo gets an auto-suggested category (Manoeuvre Sequence, Gybe Exit, Straight Line Upwind/Downwind). You can always change it per photo below.

2

Photos

Select the photos to add. Each is matched to the nearest boat-data row using the time the photo was taken (read from the photo itself).

3

Preview matches

Check the matches before publishing. An amber badge means the closest boat-data row was more than 30 minutes away — check the boat log and camera clocks agree. A red badge means no capture time or no match could be found at all.

4

Publish

This page has no upload backend of its own — every change to the live site goes through a GitHub commit. Download the manifest below, then either upload it plus the photo files yourself using GitHub's Add file → Upload files page inside the sail-shots/ folder (replacing manifest.json and adding the photos into a photos/ subfolder), or send the manifest and photo files to Claude in chat and ask for them to be published.

Edit overlay layout

Drag each box to where you want it on the photo. Positions are saved as a percentage of the photo, so they land in the same spot on every shot regardless of size. This has no upload backend either — locking in downloads an updated manifest.json for you to publish the same way as everything else.
